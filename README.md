# 🃏 TapAndDraw

> A Magic: The Gathering Game in a Browser

**Build decks. Draw cards. Control the battlefield.**

## Features

- 🔍 **Real Card Search** — powered by the Scryfall API
- 🤖 **AI Opponent** — plays lands, casts spells, and attacks
- ⚡ **Spell Effects Engine** — oracle text parsed for real effects:
  - Damage, life gain, draw, destroy, exile, bounce, counter, mill, tokens, counters, scry, tutor
- ⚔️ **Combat System** — declare attackers, resolve damage, lifelink
- 💧 **Mana Pool** — tap lands to add mana, track per-color
- 🎴 **Tokens & Counters** — create tokens, +1/+1 and -1/-1 counters
- 🪦 **Graveyard / Exile** — full zone support with viewer
- 🏆 **Win/Lose Conditions** — life total, library empty

## Getting Started

```bash
npm install
npm start
```

## Stack

- React 18
- Scryfall API (card data)
- No backend required
